# New hire onboarding checklist (support team)

_maintained by Dana — copy this for each new person, don't edit the template_

## Before day 1
- [ ] send welcome email with start time (9:30am), parking info (lot B, back of building), dress code (casual, closed-toe shoes if visiting the warehouse)
- [ ] ask IT (Kev) for laptop + Google Workspace account at least 3 business days ahead
- [ ] add to Slack: #support, #support-escalations, #general, #random, #warehouse-updates
- [ ] create Zendesk agent seat (we have 2 spare licenses as of June)
- [ ] order name badge + building fob from front desk
- [ ] assign onboarding buddy (rotate: Sofia, Marcus, Jen)

## Day 1
- [ ] building tour + warehouse walk-through with Raj or whoever is on shift
- [ ] HR paperwork w/ Beth: I-9, direct deposit, benefits enrollment (they have 30 days)
- [ ] lunch with the team (company card, keep it under $20/person)
- [ ] laptop setup, password manager, 2FA on everything
- [ ] read: support handbook, tone & voice guide, returns policy

## Week 1
- [ ] shadow buddy on live chat for 2 days
- [ ] learn the order lookup in Shopify admin
- [ ] go through the 15 most common macros (sizing, where's my order, return label, warranty)
- [ ] handle email tickets with buddy reviewing before send
- [ ] 1:1 with Dana on Friday

## Weeks 2-4
- [ ] take live chat solo during low-volume hours (Tue/Wed mornings)
- [ ] learn warranty claim process (photos required, escalate anything over $150)
- [ ] product training: try on / handle main jackets and boots in the showroom
- [ ] by end of week 4: target 25 tickets/day, CSAT above 90%

## 30-day check-in
- [ ] feedback both ways
- [ ] confirm benefits enrollment done
- [ ] remove "training" tag from their Zendesk profile
